# canu
Container image for Canu, a long-read genome assembler for PacBio and Oxford Nanopore, built from the official prebuilt Linux release binaries.

## Quick Usage

```bash
# Pull the image
docker pull docker.io/picotainers/canu:latest

# Run the tool
docker run --rm docker.io/picotainers/canu:latest canu --help
```
